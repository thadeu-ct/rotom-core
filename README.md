## Rotom Core ⚡️
Uma Central Pokémon completa, construída com paixão, JavaScript e a PokéAPI.

## 📌 Sobre o Projeto
O Rotom Core é um projeto ambicioso para criar uma plataforma web "tudo-em-um" para fãs de Pokémon. A ideia é centralizar as ferramentas mais úteis e divertidas em um único lugar, com um design temático, imersivo e totalmente focado na experiência do usuário.

## 🎨 Filosofia de Design
Este projeto está sendo desenvolvido com algumas diretrizes claras desde o início:

Mobile-First: A interface é pensada primeiro para telas de celular e tablets, garantindo uma experiência perfeita em qualquer dispositivo.

UX Temático: Cada elemento interativo é uma referência ao universo Pokémon. O ícone de configurações é um Klang, o seletor de tema é uma Moon Ball. A imersão está nos detalhes.

Paleta de Cores Inspirada: O design utiliza as cores das Poké Bolas como base. O tema claro é inspirado na Poké Ball (vermelho e branco) e o tema escuro na Ultra Ball (preto e amarelo).

## ✨ Tecnologias Utilizadas
Este é um projeto puramente frontend, consumindo dados em tempo real da PokéAPI.

## 🚀 Roadmap de Funcionalidades
O projeto será desenvolvido em módulos:

[ ] Módulo 1: A Pokédex - Uma enciclopédia interativa para consultar informações de todos os Pokémon.

[ ] Módulo 2: Jogo "Quem é esse Pokémon?" - Um divertido jogo de adivinhação com silhuetas.

[ ] Módulo 3: Montador de Times - Uma ferramenta para criar times de 6 Pokémon e analisar suas forças e fraquezas.

[ ] Estrutura Base: Navegação, temas e a página inicial.
